# **App Name**: Aces Hockey Hub

## Core Features:

- Registration: Allow users to register with their email, name, optional jersey number, phone number, and password.
- Login: Enable users to log in securely with their email and password.
- User Dashboard: Display the player's statistics, profile picture, and information about the upcoming match.
- Login Animation: Create a visually appealing animation featuring the team logo upon successful login.

## Style Guidelines:

- Primary color: Bright orange (#FF7B00) to match the logo, and capture the team's energy and spirit.
- Background color: Very dark desaturated orange (#1A140D) to create a dramatic yet branded backdrop.
- Accent color: Muted yellowish orange (#D9961C) to provide a warm analog accent.
- Headline and body font: 'Space Grotesk' sans-serif font to provide a modern athletic aesthetic.
- Smooth transitions and loading animations to improve user experience.
- Clean and intuitive dashboard layout for easy access to player information and upcoming matches.
